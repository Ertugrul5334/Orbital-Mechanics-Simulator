# Orbital Mechanics Simulator

**Python · Astrodynamics · Numerical Modelling · PID Control**

A Python simulator for placing spacecraft into orbits and moving them between orbits: two-body
and perturbed (J2, drag) orbit propagation, all six classical orbital elements, Hohmann /
bi-elliptic transfers, plane changes, a multi-burn mission planner, and a reaction-wheel PID
attitude controller. Every result is checked against analytic solutions or textbook values.

![Hohmann transfer LEO to GEO](docs/images/02_hohmann_3d.png)

## Features

| Module | What it does |
|---|---|
| `elements.py` | r, v ↔ 6 classical orbital elements (incl. circular/equatorial cases), Kepler's equation, analytic propagation |
| `propagator.py` | Hand-written RK4 and adaptive DOP853 (SciPy) integrators, event detection, re-entry stop |
| `maneuvers.py` | Hohmann, bi-elliptic, pure and combined plane changes, RTN burns, Tsiolkovsky propellant mass |
| `perturbations.py` | J2 oblateness, atmospheric drag (piecewise-exponential atmosphere), secular J2 rates, sun-synchronous design |
| `groundtrack.py` | ECI → ECEF, latitude/longitude of the sub-satellite point |
| `attitude.py` | Quaternion rigid-body dynamics, 3 reaction wheels with torque and momentum limits, PID with anti-windup |
| `mission.py` | Multi-burn mission planner: coasts, node targeting, shooting-method Hohmann targeting, Δv + propellant budget |
| `plotting.py` | 3D orbits, 2D and 3D ground tracks, attitude response, element drift |

## Quick start

```bash
git clone https://github.com/<your-username>/orbital-mechanics-simulator.git
cd orbital-mechanics-simulator
pip install -r requirements.txt
python run_all.py            # runs all 7 examples, saves figures to docs/images
python -m pytest -q          # 22 validation tests
```

Run a single example (set `SHOW_PLOTS=1` to open interactive windows instead of saving files):

```bash
cd examples
python ex02_hohmann.py
```

### Using the library

```python
from orbital_sim import OrbitalElements, propagate, hohmann, J2Perturbation, coe_to_rv, rv_to_coe

orbit = OrbitalElements.from_degrees(a=6798.137, e=0.0005, i_deg=51.64, raan_deg=30, argp_deg=90, nu_deg=0)
r, v = coe_to_rv(orbit)
traj = propagate(r, v, duration=86400, dt=20, perturbations=[J2Perturbation()])
print(rv_to_coe(*traj.final_state))

print(hohmann(6678.137, 42164.0))
# Hohmann 6678.1 km -> 42164.0 km: dv1=+2.4257 km/s, dv2=+1.4668 km/s, total=3.8926 km/s, TOF=5.275 h
```

```python
from orbital_sim import Mission, OrbitalElements, CoastToNode, Hohmann, PlaneChange, J2Perturbation

mission = Mission(OrbitalElements.circular(300, i_deg=28.5), mass_kg=2000, isp_s=320,
                  perturbations=[J2Perturbation()])
mission.add(CoastToNode()).add(Hohmann(42164.0, final_inclination_deg=0.0)).add(PlaneChange(0.0))
print(mission.run().summary())
```

## Physics and methods

**Two-body motion.** r̈ = −μ r / |r|³ with μ = 398 600.4418 km³/s². States are integrated in the
Earth-centred inertial (ECI) frame.

**Hohmann transfer.** a_t = (r₁ + r₂)/2, Δv₁ = √(μ(2/r₁ − 1/a_t)) − √(μ/r₁),
Δv₂ = √(μ/r₂) − √(μ(2/r₂ − 1/a_t)), TOF = π√(a_t³/μ).

**Plane change.** Δv = 2v sin(Δi/2), or √(v₁² + v₂² − 2v₁v₂ cos Δi) when combined with a speed change.
The simulator applies it by rotating the velocity vector at a node and checks the resulting inclination.

**J2.** Earth's oblateness (J2 ≈ 1.08 × 10⁻³) is the dominant LEO perturbation. Its secular effect on the
node, Ω̇ = −1.5 n J2 (R/p)² cos i, is what makes sun-synchronous orbits possible (Ω̇ = 0.9856°/day).

**Drag.** a = −½ ρ (C_d A/m) |v_rel| v_rel, where v_rel is relative to an atmosphere that rotates with the Earth,
and ρ comes from Vallado's piecewise-exponential model (0–1000 km).

**Mission targeting.** With J2 on, the two-body Δv₁ misses GEO by about 180 km, because the arrival radius
moves about 60 km per m/s of perigee speed. The planner uses a secant shooting method on burn 1
so that the numerically propagated apoapsis lands on the target (to within 2 m), then fires burn 2 when the
spacecraft reaches that apoapsis.

**Attitude control.** J ω̇ = −ω × (Jω + h_w) + τ_c + τ_d, ḣ_w = −τ_c, quaternion kinematics.
τ_c = −K_p e − K_i ∫e − K_d ω, where e is the attitude-error quaternion vector. Gains come from
K_p = J ω_n², K_d = 2ζω_n J (ω_n = 1 rad/s, ζ = 0.9). The integral is clamped and only runs near the
target (anti-windup).
